🏛️ Notre parti
Découvre les 3 partis dont les votes à l'Assemblée se rapprochent le plus de tes réponses.
🎤 Notre personnalité politique
Découvre les 3 député·es dont le vote personnel à l'Assemblée se rapproche le plus de tes réponses.

Méthode : pour chaque scrutin, on regarde la position majoritaire de chaque groupe parlementaire et sa cohésion interne (un parti divisé sur un sujet pèse moins sur ce sujet dans son propre score). Les groupes sont unifiés par filiation politique entre les deux dernières législatures. Les abstentions unanimes comptent comme une vraie position, pas comme une absence de donnée. Les scores affichés sont lissés statistiquement pour rester stables même quand un parti n'a pas pris position sur toutes les questions.
